# NodeSheet 用户手册

NodeSheet 是一个小巧、打开快的 Windows 桌面表格工具：先像普通查看器一样秒开大表，需要处理数据时，再用右侧的**节点图**做筛选、排序、分组、连接、改列等操作。数据处理由内置的 polars 引擎完成，**不需要另外安装 Python**。

- 系统要求：Windows 10 / 11 64 位
- 无需安装：整个文件夹放在任意位置，双击 `NodeSheet.exe` 即可
- `engine` 文件夹是节点功能用的运行环境，请和 exe 放在一起，不要删除

---

## 1. 快速上手

1. 双击 `NodeSheet.exe`，或把文件**拖进窗口**，或 `Ctrl+O` 打开。“文件”菜单下面列着**最近打开**的文件。
2. 支持的格式：`xlsx / xlsm / xls / xlsb / ods`、`parquet`、`csv / tsv`；`json / ndjson`、`arrow / feather / ipc`、`avro` 也能直接打开（交给 polars 读）。
3. 大 Excel 文件会**渐进加载**：前 1000 行立刻可见，后面在后台继续解码，状态栏显示进度。
4. CSV 的编码、分隔符自动认：中文 Windows 上 Excel 存的 GBK 编码的 CSV 不会乱码，分号 / 竖线分隔的也能分对。
5. 要处理数据：在右下的节点图里添加节点（见第 4 节），点节点右端的旗标让表格显示它的结果；也可以直接在表格上**右键**（见第 3 节）。

## 2. 界面

| 区域 | 说明 |
|---|---|
| 菜单栏 | 文件 / 节点 / 设置 |
| 工具架 | 菜单栏下方，按分类列出节点，点一下就接在选中节点后面 |
| 表格面板（左） | 页签：**表格** / **Python 脚本** / **查询计划**；顶部路径栏说明现在显示的是哪个节点的结果、行×列、用时 |
| 参数面板（右上） | 编辑选中节点的参数 |
| 节点图面板（右下） | 画布，摆放和连接节点 |
| 状态栏 | 左：运行状态点（蓝=运行中、红=出错、绿=正常）和提示；右：选区、文件信息、行×列 |

面板之间的缝可以**拖动**调整大小。`Ctrl+E` 显示 / 隐藏节点面板。设置里可以切换深色 / 浅色主题，也可以把表格与节点面板左右互换、节点图与参数面板上下互换。主题、面板布局、窗口大小下次打开时还在。

表头第二行显示每列的**数据类型**（如 `i64`、`str`、`list[i64]`、`datetime[μs]`）。Excel 里的日期照日期显示（`2023-07-15`、`2023-07-15 12:30:00`）；数字和 Excel 一样最多显示 15 位有效数字（公式算出的 `1234.5600000000002` 显示成 `1234.56`）。

## 3. 表格操作

- **选择**：点格子；拖出一块区域；点行号选整行、点列名选整列；`Shift`+点 扩选；`Ctrl+A` 全选。
- **复制**：`Ctrl+C`，`Ctrl+Shift+C` 连表头一起复制。复制的内容是制表符分隔，可直接粘贴到 Excel。
- **列宽**：拖动表头边界调整；设置 → “自动列宽”按内容重新计算。
- 设置 → “单元格自动换行”可开关换行显示。
- 设置 → “**显示格式…**”：数字和文字怎么显示（照 polars 的显示项）。浮点数可选智能（和 Excel 常规格式一样，最多 15 位有效数字）/ 完整 / 固定小数位数；可开千位分隔符（1234.56 → 1,234.56，整数列同样分组）；一格最多显示的字符数（超出写 …）；parquet / 节点结果里空值显示的文字（默认 `null`，空着就不显示）。改完点“确定”，列宽会按新格式重新取样，设置下次打开还在。
- 表格本身是**只读**的：筛选、排序等都通过节点完成，原文件不会被改动。
- **右键快捷操作**：在表格显示的那个节点后面自动建好节点并显示，节点图里看得到、能接着改。
  - 表头右键：从小到大 / 从大到小排序、统计各值的个数、去掉这列、只留这列（选了几整列时对选中的列）
  - 格子右键：只看等于这个值的行、去掉等于这个值的行

## 4. 节点图

### 4.1 基本概念

每个节点接收上游的表，做一次变换，再传给下游。节点分两级：

- **表格级节点**：在外面这层图上，节点之间传递整张表。
- **表达式节点（expr）**：双击进去，里面是一张“表达式网络”，每个节点是一个 polars 表达式，用来算列、做条件、做聚合。

打开文件时会自动建一个 `read` 源节点，并显示它。

### 4.2 画布操作（照 Houdini 的网络编辑器）

| 操作 | 方式 |
|---|---|
| 选择 | 左键点选；`Shift` 加选；`Ctrl` 减选；拖空白处框选 |
| 平移 | 鼠标中键拖，或 空格 + 左键拖 |
| 缩放 | 滚轮；双击空白复位 |
| 看全部 / 看选中的 | `H` / `G`（或点“适应”） |
| 挪动节点 | 拖动；`Shift` 连同上游，`Ctrl` 连同下游，`Alt` 复制一份 |
| 连线 | 从节点的输出端口拖到另一个节点（或它的某个输入端口）上松手；也可从输入端口往回拖 |
| 删除连线 | 点选连线后按 `Delete`；或按住 `Y` 拖过要剪断的线 |
| 删除节点 | 选中后 `Delete`（源节点不能删；删除时下游会自动改接到它的第一个上游） |
| 插入节点 | 把没有连线的节点拖到一条线上松手，即插入该连线中间 |
| 复制 / 剪切 / 粘贴 / 全选 | `Ctrl+C / X / V / A` |
| 撤销 / 重做 | `Ctrl+Z` / `Ctrl+Y`（或 `Ctrl+Shift+Z`），也在“节点”菜单里 |
| 加第二个文件 | 把文件拖到节点图上：在落点建一个 read 节点（做 join / concat 用）；拖到表格上是换成打开这个文件 |
| 旁路 | `Q` 或 `B`（节点不做事，输入原样传下去） |
| 显示 | `R`（表格显示该节点的结果） |
| 自动排列 | `L`（选了多个排选中的，否则全部） |
| 沿链选择 | `PgUp` / `PgDn` 选上游 / 下游 |
| 进入 / 返回 | 双击、回车或 `I` 进入网络；`U` 或点路径栏的“节点图”返回 |
| 右键 | 节点 / 空白处 / 连线三种菜单 |
| 查看信息 | **中键按住**节点：显示输出行列数、用时、输入、各列类型 |
| 帮助 | `F1`，或参数面板右上角的“帮助” |

节点是一个窄条：**右端旗标（蓝）** = 表格显示这个节点；**左端旗标（黄）** = 旁路。选中的节点黄框高亮。

### 4.3 添加节点

- 工具架：点按钮，节点接在选中节点下面。
- 节点图上的“添加”菜单。
- 在画布上按 **Tab** 弹出搜索，可以搜节点名、polars 方法名、中文说明；节点建在鼠标处，选着连线时直接插进这条线。

### 4.4 运行

选中并显示某个节点后按 `F5`（节点 → 运行）；“停止”可中断。引擎会缓存结果，参数和输入没变就不会重算。第一次运行节点前，程序会在打开文件时就在后台预热引擎。

---

### 4.5 选列

要填列名的参数（select 的列、unique 的子集、join 的键、expr 网络里 col 节点的列……）右边有 **“选列”** 按钮，点开是一个选列框：

- **列**：列出上游表的全部列和类型，可以搜索。点一下选上（蓝），再点一下排除（红），再点取消；选上的列按点的先后排（select 出来的列顺序就是它）。`↑` `↓` 移动，回车勾选；“全选 / 全不选 / 反选”只对搜出来的列。
- **按条件选（选择器）**：“＋ 加一条条件”，polars 的全部选择器都有——按类型（数字、整数、小数、文字、日期时间、列表、结构……、指定的类型）、按列名（是这几个、开头是、结尾是、包含、正则、只有字母 / 数字）、按位置（第一列、最后一列、第几列）、全部列。几条之间可以“或者 / 并且 / 去掉 / 只在一边”，每条还能勾“不是”取反。
- 结果 = 选上的列和条件合起来，再去掉排除的列。底下实时写着**写法**（比如 `cs.numeric() - cs.by_name("编号")`）和**现在会选到哪几列**（由 polars 算，和运行时一样）。
- 点“确定”替换参数原来的内容；勾“接在原来的后面”就追加。再打开时会把参数原来的写法读回到框里接着改。`Ctrl+回车` 确定，`Esc` 取消。
- 只要一列的参数（如 transpose 的列名来源）点一下就填好；“列: 类型”这类键值对选的是键，在框里另外填值（类型有下拉）。

## 5. 表格级节点一览

| 分类 | 节点 | 用途 |
|---|---|---|
| IO | **read** | 读 Excel / CSV / Parquet / JSON / IPC / Avro；CSV 可按行读；Excel 的 sheet 在这里选 |
| | **write** | 写出 Excel / CSV / Parquet / JSON / IPC / Avro / 剪贴板；填好文件后点“写出”按钮；CSV / Parquet 等可按某列拆成多个文件 |
| | **create** | 不读文件造表：pl.select、from_dict、from_repr、**从剪贴板粘贴**（粘贴从 Excel 复制的表格） |
| 行 | **unique** | 去重 / 标记重复 |
| | **slice** | 取前 / 后 N 行、按位置取行、反转 |
| | **drop_nulls** | 丢掉有空值的行 |
| | **fill_null** | 填空值、填 NaN、插值、位移 |
| | **upsample** | 按时间补全行 |
| 列 | **select** | 选列 / 排除列 |
| | **rename** | 改列名 |
| | **cast_columns** | 改列类型 |
| | **with_row_index** | 加行号列 |
| 表达式 | **expr** | 筛选、排序、分组聚合、新增 / 改写列（见第 6 节） |
| 统计 | **describe** | 描述统计、相关系数等 |
| 变形 | **pivot / unpivot / transpose / explode / to_dummies** | 透视、逆透视、转置、展开列表、独热编码 |
| 多表 | **join** | 连接（多个输入） |
| | **concat** | 纵向 / 横向拼接、有序合并 |
| 代码 | **sql** | 写 SQL（输入表叫 `self` / `df`，`df2`~`df4`） |
| | **code** | 直接写 polars Python 代码 |

很多节点顶部有“方式”页签（如 slice 的 head / tail），切换即可，每个选项名就是对应的 polars 方法名。

## 6. expr 节点：筛选、排序、分组、改列

expr 节点参数里先选**上下文**：

| 上下文 | 用途 | 里面要连到的输出节点 |
|---|---|---|
| with_columns | 新增 / 改写列，保留其他列 | **列** |
| select | 只保留算出来的列 | **列** |
| filter | 筛选行 | **条件**（真则保留）；页签可选“留下满足的 / 去掉满足的”，“全部满足 / 任一满足” |
| sort | 排序 | **排序键**（多个时按画布从上到下，节点上写“第 N 键”；页签选从小到大 / 从大到小） |
| group_by | 分组聚合 | 三张网络，见下 |

**进入网络**：双击节点（或选中按回车）。里面的节点从左往右连：输入（col 列、lit 常量）→ 运算 / 比较 / 条件 / 转换 / 聚合 / `str`、`dt`、`list`… 全部 polars 表达式方法 → 输出节点。要直接写表达式，用 **snippet** 节点。

**group_by 的三张网络**（路径栏上的页签切换）：

1. **分组键（整表）**：用什么分组；
2. **聚合（每组）**：每组算什么；
3. **筛选组（每组，可选）**：组算完后再筛选（相当于 having）。

“聚合”里的“then”可以直接选 sum / mean / len 等快捷方法，这时不需要聚合网络；还支持时间窗口（group_by_dynamic）和滚动窗口（rolling）。

**实用提示**

- 节点头上写着它输出的**类型**，连线按类型着色。
- 选中网络里的任一节点，表格会显示它**算出来的值**；filter 里选中“条件”会显示只按它筛过的表，路径栏写“满足 N 行（共 M）”。
- 节点摘要变黄 / 参数面板里有黄色提示，表示有问题但不算出错（比如聚合里没真正聚合、行数和表对不上）。
- **文字 ⇄ 节点**：参数面板标题栏的“转成文字”把网络变成一行 polars 表达式（可复制）；“展开成节点”反过来。在网络里按 Tab 后直接输入表达式文字，第一项“按文字建节点”会把它拆成节点。

## 7. 导出与保存

- **write 节点**：选文件、格式，点“写出”。写 Excel 用的是随包的 xlsxwriter。
- **Python 脚本页签**：把从源节点到当前显示节点的整条链导出成可直接 `python` 运行的脚本，可复制或存为 `.py`。
- **查询计划页签**：显示当前节点的 polars 查询计划（优化后 / 优化前，可“画成树”），不执行查询。
- **工程文件 .rtv**：文件 → 保存（`Ctrl+S` / `Ctrl+Shift+S`），保存节点图和界面布局；之后直接打开 .rtv。如果数据文件挪了位置，会自动在工程文件旁边找同名文件。
- 节点图改过、还没保存时，窗口标题前有 **●**；这时关窗口、退出、打开别的文件会先问要不要保存（是 = 保存，否 = 不保存，取消 = 回去接着改）。只是打开文件看看、没加节点的不会问。
- **重新加载**（文件 → 重新加载，`Ctrl+R`）：数据文件在外面改过了（切回窗口时状态栏会提醒），重新读一遍，节点图照旧、显示的节点重新算。

## 8. 自定义节点

像 Houdini 的数字资产：

1. 用 **code** 节点写 polars 代码，用 `ch("参数名")` 取参数，结果赋给 `out`。
2. 点参数面板的“参数界面”添加参数（“从代码生成参数”会按代码里的 `ch(...)` 自动加；编辑器会提示“代码用到但没定义”和“定义了但代码没用到”的参数）。
3. 点“存为类型”，它就成为新节点，出现在“添加”菜单和 Tab 搜索中。
4. 节点菜单：编辑选中节点的类型 / 新建节点类型 / 打开自定义节点文件夹 / 重新加载节点类型。

自定义节点保存在 `%APPDATA%\nodesheet\nodes\`，一个节点一个 `.py` 文件，可直接拷给别人；程序旁边的 `nodes` 文件夹里的也会自动加载。同名时优先级：工程内 > 用户 > 内置。每个节点类型还可以写帮助文档（`F1` 查看）。

## 10. 常见问题

**打开大文件很慢？** xlsx 会渐进加载，前 1000 行立刻可见；xls / xlsb / ods 按整张 sheet 解码，大表需要等一会儿。想快就转成 parquet / csv。

**节点运行报错？** 看状态栏红点和节点上的出错标记；expr 网络里出错的节点会一路标红到源头，点开看原因。参数没填会提示“参数“xxx”填的内容不对”。

**换 Excel 的 sheet？** 在 `read` 节点的 `sheet_name` 里选。

**某列显示“‹无法显示›”？** 该列类型无法格式化，只影响这一列。单元格最多显示 500 字节，列表只显示前若干个元素，开头写明总个数。

**节点功能不可用 / 引擎启动失败？** 确认 `engine` 文件夹和 exe 在同一目录且完整。引擎出了问题（比如内存不够）时，报错后面会附上引擎最后的输出，发给维护的人看。

**CSV 打开是乱码？** 一般会自动认出 GBK；还不对的话在 `read` 节点的 `encoding` 里换一个。

**表格开着时 Excel 存不了这个 CSV？** 256 MB 以内的 CSV 是整个读进来的，不占着文件；更大的会占着，先关掉查看器再存。

**能改原文件吗？** 查看器不修改原文件；要保存结果请用 write 节点。
